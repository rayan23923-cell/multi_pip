## ما أُنجز

ست أدوات، كل أداة Feature module مستقل في `Packages/TaskLensUI/Sources`. كل أداة تطبّق `ContextProducing` وتُنتج `ToolOutput`، فيتحوّل ناتجها إلى `ContextItem` عبر `ToolCaptureService`. يُحفظ العنصر في الجلسة النشطة لمساحة العمل، أو في آخر جلسة نشطة، أو في الوارد.

| الأداة | ما تفعله |
|---|---|
| Notes | إنشاء وتعديل وبحث (يتجاهل التشكيل) وحذف مع تأكيد، وتثبيت، وربط بجلسة |
| Calculator | عمليات أساسية، ونسبة مئوية بطريقة iOS (`50+10%` = 55)، وسجل (آخر 100)، ونسخ النتيجة، وإرسالها إلى Action Engine (Lens)، والحفظ |
| Browser | تبويبات (حتى 12)، وحقل عنوان (http/https فقط، ويرفض `javascript:` و`file:`)، ورجوع وتقدم وإعادة تحميل ومشاركة، وحفظ الرابط في الجلسة. `WKWebsiteDataStore.nonPersistent()`: لا كوكيز تبقى |
| PDF | فتح، وتنقل بين الصفحات، وبحث مع تمييز النتيجة، واستخراج نص الصفحة إن وُجد نص قابل للتحديد، وحفظ في الجلسة |
| Image | معاينة مع تكبير وتحريك، وحفظ، ونقطة دخول OCR تشرح أنها لاحقة |
| Text | عرض UTF-8 وUTF-16 والترميزات الأخرى، وبحث مع تمييز، وحجم خط، وخط ثابت العرض، ونسخ، وحفظ |

المستندات تُنسخ إلى مجلد التطبيق (حماية ملفات iOS، والحد 200MB)، وتُحذف ملفاتها عند حذف المستند أو مساحة العمل.

## الاختبارات
كلها ناجحة في CI ضمن تشغيل Phase 5 (الأرقام في تقرير Phase 5). اختبارات Phase 4 من نوع XCUITest تغطي:
- الملاحظات: إنشاء، وبحث، وتثبيت، وحذف مع تأكيد.
- الحاسبة: 42، و55 (نسبة)، والقسمة على صفر، والسجل.
- المتصفح: رفض عنوان غير صالح، والمسح، وفتح example.com، وتبويب ثانٍ.
- المستندات: صفحات PDF والبحث، وملف نصي، وصورة مع رسالة OCR.
- العربية: لوحة الأرقام تبقى من اليسار لليمين، و9×7 = 63.

### مشاكل ظهرت في CI وأُصلحت
- خطآن في التجميع (import ناقص لـ SwiftUI، وتمرير قيمة بين سياقات تزامن في Swift 6).
- على iOS 26 لم تكن أزرار الشريط السفلي (`.bottomBar`) تستجيب لاختبارات الواجهة، ولم يظهر رقم صفحة PDF. نقلت أزرار PDF والمتصفح والصورة إلى شريط داخل المحتوى، فصار سلوكها واحداً في كل الإصدارات.
- شريط البحث في iOS 26 بلا زر Cancel، والمتصفح يضيف "/" للعنوان، فعدّلت الاختبارات بما يناسب ذلك.

## الخصوصية و App Store
- لا AI، ولا Screen Capture، ولا Clipboard Intelligence.
- المتصفح لا يحتفظ بالكوكيز أو البيانات. `NSAllowsArbitraryLoadsInWebContent` مفعّل لمحتوى الويب فقط، لصفحات http التي يكتبها المستخدم، ويبقى ATS كاملاً لباقي التطبيق.
- الملفات محلية فقط.

## جزئي / افتراضات
- OCR نقطة دخول فقط. الاستخراج الفعلي في مرحلة لاحقة.
- PDF الممسوح ضوئياً بلا نص لا يُستخرج منه شيء، وتظهر رسالة توضح ذلك.
