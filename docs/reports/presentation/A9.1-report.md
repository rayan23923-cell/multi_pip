## PPTX DETECTION
- The type is `org.openxmlformats.presentationml.presentation`. It is recognised from the file picker's type or from the `.pptx` extension.
- The library shows **PowerPoint Presentation** instead of a generic Document.
- **Not accepted:**
  - `.ppt` (binary) and Keynote: different types, so they get the existing "not supported" message.
  - `.pptm`: a macro project inside the file is refused.
- **No false positives:** a PDF, image or text file never becomes PowerPoint.

## VALIDATION
The check reads only the ZIP central directory. Nothing is unzipped or rendered. A file is refused when:
- it is not a ZIP, or the ZIP is cut short;
- `[Content_Types].xml` or `ppt/presentation.xml` is missing (for example, a Word file renamed .pptx);
- it contains a macro project (`ppt/vbaProject.bin`);
- it has paths with `..`, an absolute path, or `\`;
- it looks like a ZIP bomb: over 1 GB uncompressed, over 10,000 entries, or an entry over 50 MB compressed more than 100×;
- it is split or ZIP64.

A refused file shows: "This file isn't a valid PowerPoint presentation (.pptx)." Nothing is stored: no file and no record.
